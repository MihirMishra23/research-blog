## Display math

rather than a client-generated image:

$$
L(\theta) =
-\mathbb{E}_{(x,y)\sim D}
\log \pi_\theta(y \mid x)

## Highlighted code

The following block has a visible language label and gains a copy button when
JavaScript is available. The highlighted source remains fully readable without
JavaScript.

```python
def causal_attention(query, key, value):
    scores = query @ key.transpose(-2, -1)
    weights = scores.softmax(dim=-1)
    return weights @ value
```

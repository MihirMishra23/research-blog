## Design decisions

### Use a quiet editorial research-notebook aesthetic

The visual system uses warm paper and ink colors, serif reading typography, monospace metadata, hairline rules, and a restrained rust accent. It avoids gradients, large promotional hero treatments, heavy shadows, and card grids.

### Prefer system fonts

The font stacks use platform and commonly installed serif and monospace faces. This avoids render-blocking font downloads, supports fast page loads, and keeps the presentation closer to an annotated notebook than a branded marketing site.

### Make theme state explicit

The theme control cycles through `system`, `light`, and `dark`, persists the selection in local storage, and applies the resolved theme before the page paints. Without JavaScript, CSS still follows the operating-system color preference and the inactive control remains hidden.

### Keep the content column narrower than the site shell

The shell supports future map width while prose is constrained to a dedicated reading measure. This preserves room for the desktop graph without allowing article text to become difficult to scan.

### Treat motion as optional

The foundation contains only short state transitions and removes them when `prefers-reduced-motion` is enabled. No decorative or ambient animation is part of the design language.

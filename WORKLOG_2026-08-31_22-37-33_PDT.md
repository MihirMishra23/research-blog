## Design decisions

- Selected a small custom deterministic build-time layout as the Action 2.3 foundation.
- Kept the approved radial root → area → topic visual geography instead of adopting Dagre's tall ranked output.
- Defined stability relative to the root so fitting the canvas does not falsely count as whole-graph movement.
- Required real label dimensions as layout inputs for both candidates.
- Deferred promotion of prototype geometry: the custom pass still needs local clearance correction and relationship routing in Action 2.3.
- Kept Dagre as a development-only comparison dependency temporarily. It is not imported by browser code and contributes no client bundle.
- Preserved authored waypoints and coordinate overrides as requirements of the hybrid implementation.

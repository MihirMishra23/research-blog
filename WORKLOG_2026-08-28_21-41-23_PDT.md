## Design decisions

### Separate the site's editorial shell from the map's handwritten canvas

The surrounding site retains the serif/monospace research-notebook foundation established in action item 3. The map itself uses a distinct handwritten drawing language so it can closely recall the original sketch without making every site control look hand-drawn.

### Use a manually composed radial SVG

The reference depends on deliberate spatial composition: `LLMs` at the center, major areas in irregular surrounding ovals, and concepts branching outward as labels. V1 will favor manually authored positions and SVG paths over automatic layout or default graph-library nodes.

### Treat red dots as semantic marks

The red dot sequences in the reference become a reusable visual signal for progression, current selection, and frontier status. They remain sparse so the map is still predominantly an ink drawing.

### Preserve scale on mobile

The desktop drawing should not be compressed into an illegible miniature. Mobile behavior will support panning or horizontal scrolling, a bottom-sheet detail view, and the required semantic list fallback.
